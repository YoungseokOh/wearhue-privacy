WearHue Privacy Policy

Effective date: October 19, 2026

WearHue processes photos locally to preview clothing colors. It does not create accounts, display ads, process payments, or upload photos to cloud AI. Firebase Analytics is enabled by default to measure the first-use and editing flow. WearHue shows this information on the first screen. You can turn Usage analytics off from Settings; the choice is stored on your device.

Photos and generated images

  • The Android system picker provides only the photo selected by the user.
  • Camera capture uses an installed camera app and an app-private temporary file.
  • Photos, masks, previews, and generated images remain on the device.
  • A result is added to the media library only after the user selects Save and WearHue verifies the file can be decoded.
  • WearHue does not upload photos or generated images.

Analytics data

When enabled, Google Analytics for Firebase receives the automatically collected first_open and standard app lifecycle/session events, plus limited WearHue events about app opening, photo source, import and garment-segmentation result, local preview result, garment-area correction or undo, and verified MediaStore save result. The SDK assigns an app-instance identifier and derives coarse location from a masked IP address for analytics reporting. Automatic screen reporting is disabled. WearHue does not send photo contents, filenames or paths, file hashes, garment masks, brush locations, or exact color values. Advertising ID collection and ad-personalization signals are disabled.

Analytics data is transmitted securely to Google Analytics for Firebase, which processes it to provide WearHue's analytics service. WearHue does not use analytics data for advertising or share it with other third parties. Turning Usage analytics off disables further Analytics collection on this device; events already sent may remain in Google's analytics reports according to the service's retention settings, and WearHue does not offer a separate request mechanism to delete those reports. Photo selection, editing, preview, and saving continue to work without network access or Analytics.

Retention and deletion

WearHue keeps normalized source photos, segmentation masks, mask corrections, and temporary export files in app-private working storage excluded from Android backup so an active edit and save survive system cache cleanup. WearHue prunes older working files after seven days and limits stored sources, mask sets, corrections, and temporary exports. Regenerable previews use cache storage and may be cleared by Android. Clearing app storage or uninstalling removes app-private working files; users can delete saved images with their gallery or file manager.

Children

WearHue is not designed for children under 13.

Changes

If a future version introduces cloud AI, advertising, payments, accounts, or other data collection, this policy and the Google Play Data safety declaration will be updated before distribution.
